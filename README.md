# 💬 T-ring — A Full-Featured Chat Application

<img width="874" alt="Screenshot 2025-04-14 at 5 58 04 PM" src="https://github.com/user-attachments/assets/6ac47f1c-1891-4654-b6b6-2134f04ff1fa" />


T-ring is a modern, feature-rich, and **real-time chat application** built with ❤️ by **Krishnan**. Designed with responsiveness, performance, and user experience in mind, T-ring lets users connect seamlessly with features like group chat, emoji support, file sharing, and more!

---

## ✨ Features

- 🔒 **Secure Real-Time Messaging**
- 😊 **Emoji Support**
- 📁 **File Sharing (Images, Docs, etc.)**
- 👥 **Group Chat Functionality**
- 📱 **Mobile-Responsive UI**
- 🕐 **Message Timestamps**

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose)
- **Real-time Communication:** Socket.IO
- **Authentication:** JWT & Cookies
- **File Uploads:** Multer / Cloudinary
- **Hosting:** Vercel / Netlify (Frontend), Render / Railway (Backend)

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/t-ring-chat-app.git
cd t-ring-chat-app
```

### 2. Install Dependencies

- **Fronten:
```bash
cd client
npm install
```
- **Backend:
```bash
cd server
npm install
```

### 3.Setup Environment Variables
- Create .env files in both frontend and backend with required config:
```bash
# server/.env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key

# client/.env
VITE_API_URL=http://localhost:5000
```

### 4. Run the App
```bash
# Run backend
cd server
npm run dev

# Run frontend
cd client
npm run dev
```
